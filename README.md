# AfroBIM

AfroBIM is road and infrastructure BIM for engineers in Africa: survey, terrain, alignments, corridors, drainage and culverts, signs and markings, coordination, 4D, 5D and Green BIM, with DWG, DXF, IFC 4.3 and LandXML exchange.

This repository holds **installers and release notes only**. The source code is private.

## Download

Get the latest version from [Releases](../../releases/latest) or from [afrobim.com](https://afrobim.com).
